# 抖X账号权限名单

模块从 `policies/access.json` 读取完整快照。此仓库公开读取，仅保存账号的授权标识，不保存明文UID、昵称、访问令牌或密码。

## 维护名单

1. 在抖X设置的“账号与授权”中复制当前账号的“授权标识”。
2. 编辑 `policies/access.json`，将完整的 `sha256:…` 字符串加入 `blacklist` 或 `whitelist` 数组，将 `revision` 增加1，然后提交。
3. 删除条目并增加 `revision` 即可撤销对应名单资格。两张名单同时出现时，黑名单优先。

- 黑名单：停用模块功能，保留权限状态与名单刷新入口；已挂载效果重启抖音后完全清除。
- 白名单：获得模块VIP资格。具体VIP功能另行分类，此名单不解锁抖音官方付费权益。
- 未入名单：普通资格；未确认身份不给VIP。
- 启动、回到前台及使用期间每分钟检查。GitHub和网络缓存可能带来延迟，不保证秒级推送；可在权限页手动刷新。
- 网络失败或名单格式错误保留最近一次有效名单，明确显示更新失败状态，不用空名单覆盖。

所有标识都必须是小写 `sha256:` 加64位十六进制字符。请勿将明文UID放到公开的提交历史中。

也可在本地运行 `python3 manage.py white add`（或 `black add`、`white remove`、`black remove`），按提示输入UID；脚本只保存哈希。提交和推送文件后生效。

## 镜像一致性

每次修改必须递增 `revision`，两个托管地址发布同一份文件。模块拒绝比本地有效缓存旧的版本，也拒绝同版本但内容不同的名单。命令行脚本会自动增加版本。计划增加 Gitee 主读取地址，目前尚未建立或接通；不要将此描述当成已经完成迁移。
